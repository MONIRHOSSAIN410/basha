# মসজিদ ও মাদ্রাসা আর্থিক ব্যবস্থাপনা সিস্টেম (Masjid & Madrasha Financial Management System)

আপলোড করা "মসজিদ এবং মাদ্রাসার আর্থিক লেনদেন পরিচালন বিধি" ডকুমেন্টের উপর ভিত্তি করে তৈরি একটি ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশন।

## যা যা আছে (Features)

- **আয় ব্যবস্থাপনা** — মাসিক চাঁদা, এককালীন দান, জুমার বাক্স, বার্ষিক মাহফিল, এতিম-মিসকিন ফান্ড (যাকাত/ফিতরা/চামড়া), সম্পদ ভাড়া, পুরনো জিনিস বিক্রি ইত্যাদি সকল খাত অনুযায়ী রেকর্ড। রশিদের কাগজের রঙ বিধি অনুযায়ী স্বয়ংক্রিয়ভাবে নির্ধারিত হয় (এতিম-মিসকিন ফান্ড = হলুদ, অন্যান্য = নীল)।
- **ব্যয় ব্যবস্থাপনা** — বেতন-ভাতা, ছাত্রদের খাবার, ইউটিলিটি বিল, রক্ষণাবেক্ষণ, মাহফিল, বৃত্তি, পোশাক, আপ্যায়ণ ইত্যাদি খাতভিত্তিক ব্যয় রেকর্ড, "অগ্রিম নগদ" ও "দরপত্র" — উভয় পদ্ধতি সমর্থিত।
- **চাহিদাপত্র (Demand Note) অনুমোদন ওয়ার্কফ্লো** — বিধির ১১.১ ধারা অনুযায়ী ডিজিটাল সাইন-অফ চেইনঃ নিরীক্ষক → অর্থ সম্পাদক → সাধারণ সম্পাদক → সভাপতি।
- **ড্যাশবোর্ড ও রিপোর্ট** — মোট আয়/ব্যয়/ব্যালেন্স, মাসভিত্তিক ট্রেন্ড চার্ট, খাতভিত্তিক পাই চার্ট, প্রিন্টযোগ্য মাসিক রিপোর্ট (স্বাক্ষরের জায়গাসহ)।
- **পাবলিক দান পেজ (`/donate`)** — লগইন ছাড়াই যে কেউ বিকাশের মাধ্যমে সরাসরি দান করতে পারবেন (bKash Tokenized Checkout)।
- **এডমিন লগইন** — একটি মাত্র এডমিন অ্যাকাউন্ট, JWT ভিত্তিক, দ্রুত/নিরবচ্ছিন্ন লগইন (কোনো বাফারিং ছাড়াই)।
- **রেসপনসিভ ডিজাইন, ডার্ক মোড, ডাইনামিক থিম কালার** (৬টি প্রিসেট কালার, সেটিংস থেকে পরিবর্তনযোগ্য), Framer Motion অ্যানিমেশন — সব ডিভাইসে (মোবাইল সহ) মসৃণভাবে কাজ করে।

## টেক স্ট্যাক

| অংশ | প্রযুক্তি |
|---|---|
| Frontend | React 19 + Vite + Tailwind CSS + Framer Motion + React Router + Recharts |
| Backend | Node.js + Express (`type: module`, ES Modules) |
| Database | MongoDB + Mongoose |
| Auth | JWT (httpOnly cookie + Bearer token) |
| Payment | bKash Tokenized Checkout API (sandbox/live) |

## ⚠️ গুরুত্বপূর্ণ নোট (এই sandbox পরিবেশ সম্পর্কে)

এই কোডটি যেই ক্লাউড ওয়ার্কস্পেসে লেখা হয়েছে, সেখান থেকে npm registry (npmjs.org) এবং কোনো ডাটাবেজ সার্ভারে নেটওয়ার্ক অ্যাক্সেস নেই — তাই `npm install` চালিয়ে ডিপেন্ডেন্সি ইন্সটল করে বা সরাসরি `npm run dev` চালিয়ে সরাসরি রান করে দেখানো এখানে সম্ভব হয়নি। কোডটি সম্পূর্ণ হাতে লেখা এবং backend-এর প্রতিটি ফাইল Node দিয়ে সিনট্যাক্স-চেক করা হয়েছে এবং frontend-এর প্রতিটি JSX ফাইল TypeScript কম্পাইলার দিয়ে সিনট্যাক্স-চেক করা হয়েছে (কোনো এরর পাওয়া যায়নি)। তবে আপনার নিজের কম্পিউটারে/সার্ভারে `npm install` করে একবার রান করে দেখে নেওয়া ভালো — নিচের ধাপগুলো অনুসরণ করুন।

## সেটআপ (নিজের কম্পিউটারে)

### প্রয়োজনীয় জিনিস
- Node.js 18+ (দেখুন: `node -v`)
- MongoDB — লোকাল ইন্সটল অথবা বিনামূল্যে [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) ক্লাস্টার

### ১. Backend

```bash
cd backend
npm install
cp .env.example .env
# .env ফাইল খুলে MONGO_URI, JWT_SECRET ইত্যাদি বসান
npm run seed:admin   # প্রথম এডমিন একাউন্ট তৈরি করবে (.env এর ADMIN_EMAIL/ADMIN_PASSWORD থেকে)
npm run dev          # http://localhost:5000 এ চালু হবে
```

### ২. Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev          # http://localhost:5173 এ চালু হবে
```

ব্রাউজারে `http://localhost:5173/login` এ গিয়ে `.env` এ দেওয়া ইমেইল/পাসওয়ার্ড দিয়ে লগইন করুন। প্রথম লগইনের পরপরই Settings থেকে পাসওয়ার্ড পরিবর্তন করে নিন।

পাবলিক দান পেজ পাবেন এখানেঃ `http://localhost:5173/donate`

### ৩. bKash পেমেন্ট চালু করা

1. [developer.bka.sh](https://developer.bka.sh) এ গিয়ে ফ্রি sandbox অ্যাকাউন্ট তৈরি করুন — সেখান থেকে `app_key`, `app_secret`, `username`, `password` পাবেন।
2. `backend/.env` এ `BKASH_APP_KEY`, `BKASH_APP_SECRET`, `BKASH_USERNAME`, `BKASH_PASSWORD` বসান।
3. লাইভ (প্রকৃত টাকা) নেওয়ার জন্য bKash Business এর সাথে merchant account এর জন্য আবেদন করতে হবে ([bkash.com/business](https://www.bkash.com/business)), তারপর `BKASH_BASE_URL` কে sandbox URL থেকে live URL এ পরিবর্তন করে দিন এবং live ক্রেডেনশিয়াল বসান।

> **রকেট (Rocket/DBBL) সম্পর্কে সততার সাথে জানানো প্রয়োজনঃ** DBBL Rocket-এর কোনো পাবলিক সেলফ-সার্ভিস ডেভেলপার API/sandbox নেই (বিকাশের মতো), তাই রকেটের জন্য সরাসরি অটোমেটেড পেমেন্ট গেটওয়ে ইন্টিগ্রেশন করা সম্ভব হয়নি। এই সিস্টেমে রকেট-এর মাধ্যমে পাওয়া দান নগদ/ব্যাংকের মতোই **ম্যানুয়ালি** (আয় ফর্মে "রকেট" মাধ্যম বেছে নিয়ে ট্রানজেকশন আইডি লিখে) এন্ট্রি করতে হবে — ঠিক বিধির মূল কাগজপত্র-ভিত্তিক পদ্ধতির মতোই।

  src/

## ডকুমেন্টের সাথে মিল (bidhi mapping)

| বিধির ধারা | সিস্টেমে যেভাবে আছে |
|---|---|
| ১. আয়ের খাতসমূহ | Income মডেলের `incomeType` enum |
| ২. চাঁদা/অনুদান প্রাপ্তির মাধ্যম | Income মডেলের `paymentMethod` (নগদ/বিকাশ/রকেট/ব্যাংক) |
| ৩-৯. রশিদ বই, রেজিস্টার, স্বাক্ষর | প্রতিটি Income/Expense এন্ট্রি ডিজিটাল রেকর্ড হিসেবে, রশিদ নম্বর ও রঙ ফিল্ডসহ |
| ১০. ব্যয়ের খাতসমূহ | Expense মডেলের `category` enum |
| ১১. ব্যয়ের মাধ্যম (অগ্রিম নগদ / দরপত্র) | Expense মডেলের `method` ফিল্ড + DemandNote অনুমোদন চেইন |
| ১২-১৫. মাসিক রিপোর্ট ও স্বাক্ষর | `/reports` পেজ — প্রিন্টযোগ্য, স্বাক্ষরের ঘরসহ |
| ১৬. সংযুক্তি (রশিদের রঙ) | Income মডেলে `receiptColor` স্বয়ংক্রিয়ভাবে fund অনুযায়ী নির্ধারিত |
